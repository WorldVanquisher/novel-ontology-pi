Phase 4 — The use phase planned

  • Timelines & forking (11): fork-point browser, branch creation, pinned state snapshots, divergence scoring
  • Simulation v1 (12): one character, folded state, voice from their own turns, Jev referee in flag-only mode. Design ratified 2026-10-22 (decision #10): every character is a state machine — their state (emotion, knowledge, goals, relationships, location, possessions) is a chain over the timeline, folded deterministically from canon deltas up to any time point; the stochastic element enters only when simulation generates forward from a folded snapshot at a fork.
