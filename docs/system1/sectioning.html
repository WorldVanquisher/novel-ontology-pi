Sectioning — intake & auto sentence segregation

status: implemented repo: src/text/sectioning.ts model: none — deterministic code

The front door of the whole system. A novel arrives as one big text; this sector cuts it into blocks (a chapter, or a long block) and segregates each block into sentences with stable IDs and character offsets. Every later decision, scene, event and proposal cites these IDs — sectioning is the provenance anchor for the entire ontology.

InputsRaw novel file (EPUB / TXT), in any language
OutputsBlocks → sentences: { id, index, paragraphIndex, text, startOffset, endOffset }
Depends onNothing — first sector in the pipeline
Feeds intoEvery patch (02–06), the miniloop engine (07), extraction (08)

Design details

  • Rule zero lives here: never ask a model what code can compute exactly. Splitting text is exactly computable, so no model — Jev or LLM — is ever consulted in this sector.
  • Language-aware rules: CJK terminal punctuation (。！？) and quote nesting (「」『』) close sentences; ellipses (……) don't split mid-thought; English abbreviations (Dr., e.g.) and decimals (3.5) don't split either.
  • Stable IDs: b0007_s0003 = block 7, sentence 3. IDs never change after assignment, so a ChangeSet proposal can cite a sentence forever.
  • Offsets are evidence: every sentence knows its exact character range in the source block, so any ontology node can be traced back to the literal text that produced it.
  • Blocks are the processing unit: ingestion rolls block by block (see sector 09); a block is one chapter when chapters exist, otherwise a long slice of text.

Implementation

  • src/text/sectioning.ts — sectionBlock(text, blockIndex); paragraph split first, then terminator scan with a closer-absorption run (。』 ?! etc.).
  • Exposed as novel section <file> — works today, prints JSON.
  • Tests: test/sectioning.test.ts — CJK quotes, English abbreviations/decimals, paragraph tracking. All passing.

Open questions — sectioning

  • Block cutting.How are chapters detected across EPUB structures and raw TXT conventions (第X章 headings, TOC entries, volume splits)? When a book has no chapters, how long is a "long block", and should blocks overlap by a few sentences for context?
  • More languages' rules.European quotes («» „ "), Korean spacing, Japanese vertical-text artifacts — which languages get hand-tuned rules in v1, and which fall back to a generic splitter?
  • Non-narrative matter.Author notes, afterwords, illustrations' captions, tables — sectioned like prose, flagged, or skipped?
  • Damaged text.OCR errors and missing punctuation in fan-translated files — how much fuzz should the splitter tolerate before a block is flagged for the merge gate?
