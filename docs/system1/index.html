System 1 — The Autostep Miniloop

The fast, local decision system inside the CLI. It reads a novel the way a careful reader skims structure — where scenes break, which sentences are dialogue, whose names appear, who is actually in the room, who is speaking. It decides structure; it never writes the ontology. Everything it concludes becomes a proposal for the main agent to approve at the merge gate.

design v0.1 patch catalog: open for discussion companion: DESIGN.md

The architecture

Rule zero: never ask a model what code can compute exactly. Sectioning, offsets, and scanning for known names are code. Jev is only asked genuinely ambiguous questions — and it answers with probabilities, not text, in ~70–500 ms, batched: one call per window, all questions at once. The one hard boundary in the graph: nothing crosses from ChangeSet to storage except through the merge gate, on the main agent's approval.
