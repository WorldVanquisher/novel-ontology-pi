Dialogue detector — which sentences are spoken

status: v1 patch (skeleton) repo: src/autostep/patches/dialogue-detector.ts model: Jev · choice + noul

The sector the whole design was first sketched around: the dialogue detector receives sentence IDs from the auto segregation (sector 01) and chooses which ones are dialogue — then stitches multi-sentence turns, answering "which sentences belong to this dialogue".

InputsSentence IDs + text for one scene span; the previous turn (for stitching)
OutputsDialogue units — ordered groups of sentence IDs — into shared context
Depends on01 Sectioning, 02 Scene spans
Feeds into06 Speaker attribution (units are what get attributed), 08 Extraction

Decision questions

segment_kind · choice — Classify this sentence: dialogue (spoken aloud) / narration / interior_monologue (unspoken thought) / description (setting & sensory detail).
continues_previous_dialogue · noul — Does this sentence continue the same spoken turn as the preceding dialogue sentence (same speaker, no narration break)? This is the stitch.
is_interrupted_turn · noul candidate — Was this turn cut off mid-speech? Prevents stitching two different speakers across an interruption.

Design details

  • Quotes are a hint, not the rule: 「」 makes dialogue likely, but narration quotes terms and thoughts too — that's why this is a decision patch, not a regex.
  • Speech tags are narration: 她说道。 classifies as narration — but it carries the speaker hint that sector 06 leans on, so the classification keeps it adjacent to its turn.
  • Units, not sentences, flow downstream: speaker attribution and extraction never see loose dialogue sentences, only stitched units.

Implementation

  • src/autostep/patches/dialogue-detector.ts — two questions per sentence; groups by kind + continues flag into ctx.accepted.dialogueUnits.
  • Covered by the mocked-Jev miniloop test: a dialogue sentence is grouped into a unit with zero live model calls.

Open questions — dialogue detection

  • Unquoted dialogue.Some Chinese web novels run dialogue with —— or no marks at all. Does segment_kind hold up, or does this sector need a language/style pre-pass?
  • Speech-tag attachment.Should 她说道。 be formally attached to its turn as metadata (it names the speaker), or left as plain narration that sector 06 merely reads?
  • Thought conventions.Interior monologue appears as 『』, italics, or bare text depending on the source. Per-novel style profiles — worth having?
  • Nested quotation.A character quoting another character: one unit with a nested speaker, or two units?
