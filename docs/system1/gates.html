Confidence gates — how a probability becomes a decision

Jev never says "yes" — it says "0.83". Deterministic code routes on that number, per patch, with three outcomes. This routing is what makes the miniloop recursive: uncertainty doesn't fail, it narrows.

‹ 0.55 · escalate
subdivide the window, or hand this unit to the work LLM 0.55–0.85 · re-ask
expand context (previous/next scene), decide again ≥ 0.85
accept

Accept

The decision enters the shared context, later patches build on it, and any proposal it supports joins the block's ChangeSet with its confidence attached.

Re-ask with more context

The window grows — the previous scene, the next sentences, more of the state summary — and the same question is decided again. Most ambiguity in fiction is just missing context.

Escalate / subdivide

Either the window splits smaller (a tangled paragraph becomes two simpler ones), or the unit goes to the work LLM to adjudicate. Its verdict is written back and the loop continues. A brand-new character candidate escalates immediately — discoveries deserve the big model.

Why this shape

  • Cost follows difficulty. Jev calls are ~$0.042 per million input tokens and unmetered on output; the work LLM only ever sees the hard fragments.
  • Thresholds are per patch. Speaker attribution can tolerate 0.80; presence — which feeds simulation state — holds at 0.85. Each patch carries its own gates in code.
  • Thresholds are tuned, not guessed. The 0.85 / 0.55 split is a starting proposal, to be calibrated on a golden chapter once the Jev test key is wired. The Jev model version is pinned in the novel's manifest so tuned thresholds stay meaningful.
  • Nothing is silently decided. Units that stay uncertain after escalation are listed in the ChangeSet review for the main agent — and the user — to see.
